# ExploreWithMe — Graduation Project

## О проекте

**ExploreWithMe** — распределённая платформа для публикации, поиска и совместного посещения мероприятий.

Пользователи могут создавать события, подавать заявки на участие, оставлять комментарии, оценивать мероприятия и получать персональные рекомендации на основе собственной истории взаимодействий.

Проект реализован в виде набора независимых микросервисов, взаимодействующих через Spring Cloud инфраструктуру, gRPC и Apache Kafka.

---

# Основные возможности

### Работа с мероприятиями

* создание и управление мероприятиями;
* поиск мероприятий по различным параметрам;
* модерация событий администраторами;
* работа с категориями и подборками;
* просмотр подробной информации о мероприятиях.

### Работа с заявками

* регистрация на мероприятия;
* подтверждение и отклонение заявок;
* контроль лимита участников.

### Комментарии

* создание комментариев;
* редактирование комментариев;
* удаление комментариев;
* модерация контента.

### Персональные рекомендации

* фиксация пользовательских действий;
* анализ взаимодействий пользователей с мероприятиями;
* вычисление сходства мероприятий;
* получение персонализированных рекомендаций;
* получение списка похожих мероприятий.

# Архитектура системы

Проект построен по микросервисной архитектуре.

## Core Services

### event-service

Сервис управления мероприятиями.

Функции:

* создание мероприятий;
* поиск мероприятий;
* получение карточек мероприятий;
* получение рекомендаций;
* обработка пользовательских лайков;
* получение рейтинга мероприятий из рекомендательного сервиса.

### request-service

Сервис управления заявками на участие.

Функции:

* создание заявок;
* подтверждение заявок;
* отмена заявок;
* отправка информации о регистрации пользователей в рекомендательную систему.

### user-service

Управление пользователями системы.

### comment-service

Работа с комментариями пользователей.

---

## Recommendation Services

Рекомендательная система выделена в отдельный набор микросервисов.

### collector

Получает пользовательские действия по gRPC и публикует их в Kafka.

Поддерживаемые действия:

* просмотр мероприятия;
* регистрация на мероприятие;
* лайк мероприятия.

### aggregator

Выполняет потоковую обработку действий пользователей.

Функции:

* чтение действий из Kafka;
* расчёт косинусного сходства мероприятий;
* поддержка инкрементального пересчёта коэффициентов;
* публикация результатов в Kafka.

### analyzer

Предоставляет рекомендации через gRPC.

Функции:

* хранение истории взаимодействий пользователей;
* хранение коэффициентов сходства мероприятий;
* вычисление персональных рекомендаций;
* поиск похожих мероприятий;
* расчёт рейтингов мероприятий.

# Рекомендательная система

## Фиксация действий пользователей

Система отслеживает:

| Действие | Вес |
| -------- | --- |
| VIEW     | 0.4 |
| REGISTER | 0.8 |
| LIKE     | 1.0 |

Для каждого пользователя и мероприятия хранится только действие с максимальным весом.

---

## Расчёт сходства мероприятий

Используется косинусное сходство:

similarity(A,B) = Smin(A,B) / (√SA × √SB)

где:

* SA — сумма весов взаимодействий с мероприятием A;
* SB — сумма весов взаимодействий с мероприятием B;
* Smin(A,B) — сумма минимальных весов пользователей для пары мероприятий.

Aggregator выполняет инкрементальный пересчёт коэффициентов без полного пересчёта всей матрицы.

---

## Генерация рекомендаций

### Похожие мероприятия

Алгоритм:

1. Получить коэффициенты сходства выбранного мероприятия.
2. Исключить мероприятия, с которыми пользователь уже взаимодействовал.
3. Отсортировать по коэффициенту сходства.
4. Вернуть N лучших результатов.

### Персональные рекомендации

Алгоритм:

1. Получить последние взаимодействия пользователя.
2. Найти похожие мероприятия.
3. Исключить уже просмотренные.
4. Найти ближайших соседей.
5. Рассчитать предсказанную оценку.
6. Вернуть мероприятия с максимальной оценкой.
